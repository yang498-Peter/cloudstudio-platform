# CloudStudio Potree Skybox

Default point-cloud viewer skybox.

- Asset: Kloofendal 48d Partly Cloudy (Pure Sky)
- Source: https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky
- License: Poly Haven CC0
- Original reference file: `kloofendal_48d_partly_cloudy_puresky_4k.exr`

The production viewer does not ship or load the large EXR directly. These six
JPG cube-map faces are generated from Poly Haven's tonemapped JPG and resized to
1024 x 1024 per face so the default skybox stays lightweight for customer links.
