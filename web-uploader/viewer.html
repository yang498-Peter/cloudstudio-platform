This coordinate workflow supports local coordinates, WGS84, Web Mercator, UTM/UPS, and offline authority-code lookup for common CRS definitions. Parameter files can be imported as `.prj / .wkt / .txt / .json / .csv`. Grid resources can be attached from `.gsb / .gtx / .tif / .tiff`, while `.ggf / .grd` may require conversion to a PROJ-compatible grid before they can be used. Horizontal grids can participate in interactive coordinate display when the current transform chain supports them; vertical geoid and more generic grids are applied mainly through the native PROJ/pyproj transform and export pipeline.

ℹ About CloudStudio

CloudStudio is a professional point cloud workspace for visualization, measurement, clipping, and section-based analysis.

This testing build provides results for reference only. Please independently verify measurements, coordinate systems, transformations, and output accuracy before production or delivery use.

Created by Peter Yang
LiDAR Product Manager

Potree core © Markus Schütz

⚠ Testing Version Notice
This build is for testing and evaluation only. All measurements, classifications, alignments, exports, and derived analysis results must be checked independently.

Please verify coordinate systems, units, transformations, geometry, and output accuracy before using any result in production, survey, engineering, forestry, or delivery work.

By continuing to use this testing build, the operator accepts responsibility for checking suitability and accuracy. Unknown defects or algorithm limitations may still exist.
